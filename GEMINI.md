# Reglas de trabajo para el agente

1. **Siempre se itera primero con el usuario antes de ejecutar cualquier acción.** Solo cuando toda la lógica esté discutida y aprobada por el usuario se ejecuta lo acordado.

2. **Registro de decisiones (ADR).** Existe (o se creará) un archivo `ADR.md` en la raíz del repo. Cada vez que se haga una implementación y el usuario la testee y la apruebe, se actualiza el `ADR.md`. El archivo se inicia con la estructura estándar de un ADR una vez se haya decidido el camino que tomará la app.
